# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private reporting instead: on the repository page open the **Security** tab and choose **Report a vulnerability** (a private Security Advisory). Include what you found, steps to reproduce, and the OGphotos version and OS.

OGphotos runs only on `127.0.0.1` and works on local files, so reports about anything that exposes the app beyond localhost, or that lets a file be read, written or deleted outside the data folder, are especially welcome.
