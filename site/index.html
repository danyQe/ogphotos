OGphotos

OGphotos — clean up your Google Takeout export. Duplicates, similar shots, faces. 100% offline.

Download

Windows (x64)OGphotos-Setup-<ver>.exe macOS (Apple Silicon, macOS 14+)OGphotos-<ver>.dmg Linux (x86_64/aarch64)ogphotos-<ver>-linux.tar.gz

First launch

  • The app is unsigned, so your OS will warn you the first time.
  • Windows: SmartScreen shows "Windows protected your PC". Click More info, then Run anyway.
  • macOS: right-click the app and choose Open. If it is still blocked, open System Settings → Privacy & Security and click Open Anyway.
  • The first run downloads about 1 GB once (usually 5–30 min), or about 4 GB on a PC with a recent NVIDIA GPU so OGphotos can use it. Later launches start in seconds.
  • Then it asks you to pick a photo folder and download the models:
    • EmbeddingGemma 2 — required, Apache-2.0.
    • InsightFace buffalo_l — optional, non-commercial research use only.

Features

  • Exact duplicates by SHA-256, including Takeout's year-folder plus album-folder copies.
  • Near-duplicates by perceptual hash.
  • Similar-shot groups from EmbeddingGemma 2 embeddings, with a suggested best photo.
  • Fast review with keyboard shortcuts to keep the best and trash the rest.
  • Faces and People found and clustered on your CPU.
  • Library sorted by date taken, using EXIF and Takeout sidecars.
  • Safe trash: only Empty trash deletes files. Your source folder is never modified.
  • Formats: JPG, PNG, HEIC/HEIF, WEBP, GIF; MP4 and MOV videos (exact duplicates only).

Privacy

Nothing leaves your machine after setup. The app listens on 127.0.0.1 only, with no update checks and no telemetry. The only network use is the model download you start yourself.
